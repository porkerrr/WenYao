# WenYao v1.0.0

源码配置 `versionName = 1.0.0`、`versionCode = 2`。

## 主要功能

- 三铜钱逐爻起卦或自动完成剩余爻，按 6/7/8/9 规则计算六爻、本卦、动爻与变卦。
- 本地 Room 历史记录与独立 AI 解读 revision；基础卦先保存，AI 失败不会丢失已保存记录。
- 业务起卦结果先确定，再播放对应 3D 铜钱动画；提供 Compose 页面、导航和解读状态动画。
- SiliconFlow 与 DeepSeek 官方 BYOK，按供应商独立保存加密凭据。
- 默认关闭的实验性专业排盘与静态核心事实能力门。

已有修复包括真机铜钱渲染、首页输入法与系统安全区域适配、重复返回导航防护及阅读位置恢复。具体历史见 [CHANGELOG](../../CHANGELOG.md)。

## 实验功能与已知限制

专业规则集为 `wenyao-mainstream` / `1.0.0-static-cross-validated`。`CROSS_VALIDATED` 仅表示静态结果与冻结参考实现交叉比对，不等于领域专家确认、`VERIFIED` 或科学预测能力验证。当前 AI 仅接收 `STATIC_CORE` 专业事实；月日干支、旬空、六神和变爻六亲等在本地实验面板展示，不作为已开放的 AI 专业能力发送。

当前版本公开截图待补充；构建、设备测试的执行边界见 [版本验证记录](../RELEASE_VERIFICATION.md)。专业排盘准确性、真机兼容性与供应商当前服务可用性不因本次发布而获得额外保证。

## 安装与构建

最低 Android API 26；compile / target API 35。构建需要 JDK 17、Android SDK Platform 35 与 SDK Build Tools，使用仓库自带的 Gradle Wrapper。

Windows 在仓库根目录运行：

```powershell
.\scripts\Android-Task.ps1 -Mode Preflight
.\scripts\Android-Task.ps1 -Mode Build
.\gradlew.bat lint
.\gradlew.bat :app:assembleRelease
```

其他平台配置好 JDK 与 SDK 后，可运行 `sh ./gradlew test lint :app:assembleDebug :app:assembleRelease`。测试、SDK 配置及保留数据安装步骤见 [贡献指南](../../CONTRIBUTING.md) 和 [Android 工作流](../ANDROID_WORKFLOW.md)。构建成功不表示设备或视觉验收通过。

正式 APK 附件为 `WenYao-v1.0.0.apk`，下载后可用 `SHA256SUMS.txt` 检查完整性。最低 Android 8.0 / API 26。签名凭据不在仓库中，自行构建的 unsigned APK 不等同于官方签名附件。第三方许可随 `THIRD_PARTY_NOTICES.zip` 一并提供。

## AI / BYOK

在设置中选择供应商并输入自己的 API Key。当前源码使用 SiliconFlow 的 `deepseek-ai/DeepSeek-V4-Flash` 或 DeepSeek 官方的 `deepseek-flash`；前者发送 `enable_thinking=false`，后者发送 `thinking.type=disabled` 并省略 `reasoning_effort`。模型是否可用取决于供应商与账户状态。

配置后，保存新卦例会自动请求解读，重新解读也会产生 API 请求与相应费用。未配置 Key 时可使用基础功能，不会生成假解读。Key 使用 Android Keystore / AES-256-GCM 加密并保存在 `noBackupFilesDir`，不写入卦例历史。

问题、基础卦象和允许的专业事实由设备通过 HTTPS 直接发送至所选供应商，不经过问爻开发者服务器；不发送原始起卦时间、IANA 时区或完整专业快照。历史数据库没有应用层加密，删除本地数据不等于撤销 Key 或删除供应商数据。请阅读 [隐私说明](../../README.md) 和 [安全说明](../../SECURITY.md)。
